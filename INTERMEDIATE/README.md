# 🌍 Global Superstore Analysis

## Sales Performance Analysis Using Python

This project analyzes the **Global Superstore** dataset to understand sales performance across products, categories, customers, and regions.

The project follows a complete data-analysis workflow, starting with the raw dataset and progressing through data cleaning, exploratory analysis, visualization, and report generation.

---

## 📌 Project Objectives

- Clean and prepare the raw dataset
- Perform exploratory data analysis
- Analyze sales performance
- Analyze product and category performance
- Analyze regional and geographic performance
- Identify important business trends
- Create meaningful visualizations
- Generate business-oriented insights
- Produce a final HTML analysis report

## 📁 Repository Contents

### 📂 Raw Data

`data/raw/Global_Superstore_Raw.csv`

Contains the original, unmodified source dataset used for the analysis.

### 📂 Cleaned Data

`data/cleaned/Global_Superstore_Cleaned_by_notebook.csv`

Contains the cleaned dataset produced through the analysis notebook.

### 📓 Analysis Notebook

`notebooks/Global_Superstore_Python_Analysis.ipynb`

Contains the complete Python workflow for:

- Data loading
- Data inspection
- Data cleaning
- Exploratory analysis
- Data visualization
- Business analysis

### 📊 Analysis Report

`outputs/Global_Superstore_Python_Report.html`

Contains the final generated analysis report and visual outputs.
